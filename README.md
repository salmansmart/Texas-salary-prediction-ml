# Texas-salary-prediction-ml
💰 Texas Salary Prediction (Machine Learning)

📌 Overview

Salary prediction is an important problem in data analytics and HR domains. This project focuses on predicting employee salaries in Texas based on various features such as experience, job role, education, and other relevant factors using machine learning models.

---

🎯 Objective

- Build a regression model to predict salaries accurately
- Identify key factors influencing salary
- Provide insights for data-driven decision-making

---

🧠 Tech Stack

- Programming Language: Python
- Libraries: Pandas, NumPy, Matplotlib, Seaborn
- Machine Learning: Scikit-learn

---

📂 Dataset

- Texas salary dataset (structured data)
- Features may include:
  - Experience
  - Education
  - Job role
  - Location
  - Skills

---

⚙️ Project Workflow

1. Data Preprocessing
   
   - Handling missing values
   - Encoding categorical variables
   - Feature scaling

2. Exploratory Data Analysis (EDA)
   
   - Salary distribution analysis
   - Correlation between features
   - Outlier detection

3. Feature Engineering
   
   - Feature selection
   - Transformations for better model performance

4. Model Building
   
   - Linear Regression
   - Decision Tree Regressor
   - Random Forest Regressor

5. Model Evaluation
   
   - R² Score
   - Mean Absolute Error (MAE)
   - Mean Squared Error (MSE)

---

📊 Results

- Model achieved strong predictive performance
- Identified key drivers affecting salary
-acheived r2_score=60%
---

📈 Key Insights

- Experience significantly impacts salary
- Certain job roles have higher salary ranges
- Education level influences earning potential
